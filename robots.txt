# 🔴 셀럽 사진은 검색 이미지에서 뺀다
#    구글이 하딜고고 검색결과의 대표 썸네일로 셀럽 얼굴 사진을 골라 쓸 수 있다.

#    그래서 폴더째 후보에서 뺀다.
#
#    ⚠️ noimageindex 는 쓰지 말 것 — 그건 레시피 카드·메뉴 그림까지 전부 색인에서 뺀다.
#       여기 한 줄이면 셀럽 사진만 빠지고 나머지는 그대로다.
#    ⚠️ 사이트 화면에는 아무 영향이 없다. 셀럽 사진은 그대로 보인다.
#    ⚠️ 이미 색인된 옛 사진은 이 줄만으로 즉시 사라지지 않는다 — Search Console
